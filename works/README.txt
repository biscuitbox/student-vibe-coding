학생 작품을 올리는 폴더입니다. (강사용)

[이 폴더에 올리면 생기는 주소]
  https://biscuitbox.github.io/student-vibe-coding/works/파일이름.html
  올린 뒤 1~2분 지나야 열립니다. 바로 안 열려도 잠시 기다리세요.

[파일 이름 규칙]
  4차시 학습 도구 : todo_이름.html    예) todo_minsu.html
  6차시 게임      : game_이름.html    예) game_minsu.html
  - 반드시 영문. 한글·띄어쓰기가 들어가면 주소가 깨집니다.
  - 확장자가 .html 인지 확인. .html.txt 로 제출되는 경우가 가장 많습니다.

[올리기 전에 반드시 확인]
  1. 파일 안에 학생 실명·연락처·학교 이름·사진이 없는지
     → 저장소가 공개이므로 올리면 누구나 볼 수 있습니다. 별명만 쓰게 했는지 확인.
  2. 메모장이나 브라우저로 한 번 열어서 실제로 작동하는지
  3. 파일 안에 파이어베이스 설정값 말고 다른 키가 들어 있지 않은지

[올리는 시점 — 세 번]
  4차시 끝    todo_*.html   (이걸 올려야 5차시 로그인 실습이 가능합니다. 빠뜨리면 5차시가 막힙니다.)
  5차시 중간  로그인 붙인 todo_*.html 다시 올리기
  6차시 초반  game_*.html   (전시관에 등록할 주소가 됩니다.)

[올리는 방법 — 웹에서]
  1. github.com/biscuitbox/student-vibe-coding 접속
  2. works 폴더 열기 → Add file → Upload files
  3. 파일을 한꺼번에 끌어다 놓기
  4. 아래 Commit changes 클릭
  자세한 절차는 firebase_setup.html 의 깃허브 페이지 부록에 있습니다.
