    두더지를 누르면 점수가 오르고, 가끔 폭탄이 나오는데 그걸 누르면 점수가 깎여.

[반드시 지킬 규격]

- 결과는 숫자 하나(점수)로 나오고, 높을수록 잘한 거야.
- 코드 맨 위에 const GAME_ID = 'my-game'; 를 만들어 줘.
- 게임이 끝나면 gameOver(점수) 함수를 부르고, 그 함수 안에서 점수를 화면에 보여 줘.
- 혼자 하는 게임이고, 마우스나 손가락 터치만 써.

[디자인]
- 화면 맨 위에 남은 시간과 현재 점수를 크게.
- 글자는 크게, 휴대폰에서도 가로 스크롤 없이 보이게.
- 버튼을 누르면 눌렸다는 게 바로 보이게 해 줘.

[데이터]
- 아직 저장 기능은 넣지 마. 다음 시간에 붙일 거야.

  const key = 'best_' + GAME_ID;

  roundsEl.innerHTML = '';
  for (let i = 0; i < TOTAL; i++){
    const d = document.createElement('div');
    d.className = 'dot' + (times[i] !== undefined ? ' on' : '');

  pad.className = 'pad' + (cls ? ' ' + cls : '');

      const w = document.createElement('span'); w.className = 'who2'; w.textContent = r.nickname || '익명';
      const s = document.createElement('span'); s.className = 'sc'; s.textContent = r.score;
      row.append(n, w, s);
      box.appendChild(row);
    });

    const mineIdx = list.findIndex((r) => r.uid === uid);
    if (mineIdx >= 5){
      const row = document.createElement('div');

      const n = document.createElement('span'); n.className = 'n'; n.textContent = (mineIdx + 1);
      const w = document.createElement('span'); w.className = 'who2'; w.textContent = list[mineIdx].nickname || '나';

      box.appendChild(row);
